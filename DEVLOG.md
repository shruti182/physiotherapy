## Tips for using this

- Keep entries short — bullet points, not paragraphs. This is a log, not a report.
- "Blocked / needs follow-up" is the most valuable section — it's your own memory of what you were mid-way through, so future-you doesn't have to reconstruct it.
- If something breaks and you fix it, note *why* it broke, not just that it's fixed — that's the part you'll forget.
- Commit this file alongside your code changes so the history lines up with your git log.
