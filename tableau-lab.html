Calculated Fields Row-level formula, then aggregate

A calculated field runs once per row of raw data before any aggregation happens. Drag it to a shelf and Tableau aggregates it using the function you choose.

Table Calculations Compute across the visible table

Table calculations run after Tableau aggregates the data. They compare or move values across rows or columns that are already in your view — they can't see data that isn't on the sheet.

LOD Expressions Fix the level of detail independently

Level of Detail expressions let you lock a calculation to a specific grain — no matter what dimensions are on the view. FIXED ignores the view, INCLUDE adds a dimension, EXCLUDE removes one.
